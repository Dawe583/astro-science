Run the research loop for the astro-science workspace.

1. Read `CONTEXT.md`, the `astro-science` skill, and the `astro-theory` skill.
2. State the question and hypothesis in one sentence each.
3. Derive step by step in LaTeX; define every symbol; state assumptions.
4. Sanity-check: dimensions, limiting cases, numeric spot-check.
5. Produce a labeled figure with units.
6. Write a report and update the matching `premium/theory_*.md` and the wiki page in
   `research/wiki/` (with `[[links]]`).

No invented physics. Distinguish exact results from approximations and
model-dependent statements.
