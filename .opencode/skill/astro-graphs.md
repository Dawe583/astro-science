# astro-graphs

Understand-Anything is installed globally (`~/.understand-anything/repo`, skills in
`~/.agents/skills`, plugin built). Data dir for this project: `.ua/` (English).

## The three graphs (all committed)

| Graph | Command | Output | Built (2026-10-20) |
|---|---|---|---|
| Code graph — root + subdomain merge | `/understand` | `.ua/knowledge-graph.json` | 167 nodes / 92 edges, 10 layers, 18 tour steps |
| Domain flows | `/understand-domain` | `.ua/domain-graph.json` | 4 domains / 9 flows / 38 steps (51 nodes, 52 edges) |
| Knowledge wiki graph | `/understand-knowledge research/wiki` | `.ua/wiki-graph.json` | 16 articles, 24 entities, 34 claims (81 nodes, 175 edges) |

Supporting files:

- `.ua/exotic-compact-objects-knowledge-graph.json` — subdomain code graph for the
  nested repo (92 nodes / 62 edges). Rebuilt whenever subdomain files change, then
  merged into the root graph.
- `.ua/merge-report.json` — before/after node and edge counts of the last merge.
- `.ua/cohesion-edges.json` + `.ua/tools/add-cohesion-edges.py` — deterministic,
  idempotent cross-links (docs ↔ scripts ↔ wiki topics) that reduce graph
  fragmentation. Re-run the script after every code-graph rebuild.
- `.ua/refresh-requested.json` — generated by the drift loop; lists exactly which
  files need re-analysis. Absence means the graphs are current.

## Workflow

1. **First build (full):** `/understand --language en`, `/understand-domain`,
   `/understand-knowledge research/wiki`.
2. **Drift check before any refresh** (no LLM):

   ```
   .opencode/loops/refresh-graphs.sh
   ```

3. **Refresh (incremental by default):** re-run `/understand`; only changed files are
   re-analyzed. If `.ua/refresh-requested.json` lists subdomain files, rebuild the
   subdomain graph and merge:

   ```
   python3 ~/.agents/skills/understand/merge-subdomain-graphs.py
   .venv/bin/python .ua/tools/add-cohesion-edges.py
   ```

4. **Explore:** `/understand-dashboard`.
5. **Ask / diff / explain:** `/understand-chat "<question>"`, `/understand-diff`,
   `/understand-explain <file>`, `/understand-onboard`.

## How the graphs are used by the loops

- **Research loop** (`research-loop.sh`) → ask `/understand-chat` for background,
  `/understand-explain` for the relevant derivation code, and check
  `.ua/wiki-graph.json` for existing claims so new theory docs link back to the wiki.
- **Data refresh** (`refresh-data.sh`) → after a sweep, run `refresh-graphs.sh` so the
  code graph reflects moved output paths and new scripts.
- **Notebook health** (`notebook-health.sh`) → failing notebooks are located with
  `/understand-explain`; passing runs clear drift for the notebooks they touched.
- **Orchestrator** runs data → notebooks → drift and writes
  `.opencode/loops/logs/latest-status.json` (`graphRefreshRequested: true|false`).

## Configuration

- `.ua/config.json` — `outputLanguage: "en"`, `autoUpdate: false`.
- `.ua/.understandignore` — excludes `.venv`, caches, cloned upstream repos
  (`notebooks/`, `mast_notebooks/`, `gaia-jupyter-notebooks/`, `AstroInteractives/`),
  and large binaries.
- The nested `exotic-compact-objects` repo **is** analyzed (code/models/scripts/
  notebooks/premium markdown), but its data, figures and generated HTML are excluded —
  the subdomain scan must reproduce exactly 84 files.
- `wiki-graph.json` is deliberately **not** named `*knowledge-graph*`: the subdomain
  merge script globs that name and would ingest the wiki graph as a code subdomain.

## Keeping it fresh

The drift loop is scheduled autonomously (cron/heartbeat). After it reports drift, an
agent session runs `/understand` and re-applies cohesion edges. To auto-update on every
commit, run `/understand --auto-update` once (writes `autoUpdate: true` to config).

## Sharing

Commit `.ua/` (minus `intermediate/`, `tmp/`, `.trash-*`, `diff-overlay.json`,
`.understandignore`). Teammates can view all graphs without an LLM:

```
npx https://github.com/Egonex-AI/Understand-Anything/releases/latest/download/understand-anything-viewer.tgz /home/dawe/Projects/astro-science
```

For graphs >10 MB, use git-lfs (see the Understand-Anything README).
